Cozy Nature Editör

Bu klasörü VS Code ile açın. Terminal: py -m http.server 8001
Tarayıcı: http://localhost:8001
Mevcut 8000 projeniz etkilenmez.
Three.js için internet gereklidir.
Model dosyaları kullanıcı tarafından sağlanan Stylized Nature MegaKit paketinden alınmıştır. Lisans koşullarını kaynak paketten kontrol edin.
